# مدار — آرشیو فعالیت‌ها و آثار

پلتفرم نمایش فعالیت‌ها و آثار یک مجموعهٔ تولید محتوا، با نقشهٔ مداری زمان‌محور.
این پروژه دو بخش دارد: **بک‌اند** (Node.js + Express + SQLite) و **فرانت‌اند** (React + Vite).

## پیش‌نیازها
- Node.js نسخهٔ ۱۸ یا بالاتر
- برای بک‌اند، هنگام `npm install` بستهٔ `better-sqlite3` کامپایل می‌شود؛ روی ویندوز ابزار build (Visual Studio Build Tools) و روی لینوکس `build-essential`/`python3` لازم است. (در صورت تمایل می‌توان به‌جای آن از درایور دیگری استفاده کرد.)

## اجرای بک‌اند
```bash
cd server
npm install
npm start        # روی http://localhost:4000
```
بار اول، دیتابیس `server/madar.db` ساخته و با چند نمونه پر می‌شود.
فایل‌های آپلودشده در `server/uploads` ذخیره می‌شوند.

## اجرای فرانت‌اند
```bash
cd web
npm install
npm run dev      # روی http://localhost:5173
```
Vite درخواست‌های `/api` و `/uploads` را به بک‌اند روی پورت ۴۰۰۰ پراکسی می‌کند.
سپس مرورگر را روی http://localhost:5173 باز کنید.

## امکانات
- **نقشهٔ مداری با بازهٔ زمانی:** مرکز نقشه یک بازهٔ زمانی (مثلاً خرداد ۱۴۰۴ تا خرداد ۱۴۰۵) است و فقط فعالیت‌هایی که تاریخ شروعشان در آن بازه است نمایش داده می‌شوند.
- **نقطه‌های قابل جابه‌جایی و تغییر اندازه:** در «حالت مدیریت» می‌توان نقطه‌ها را کشید، اندازه‌شان را تغییر داد و تعداد مدارها را کم/زیاد کرد.
- **انیمیشن‌های قابل انتخاب:** تپش مرکز، شناوری نقطه‌ها و چشمک‌زن — هرکدام جداگانه فعال/غیرفعال می‌شوند.
- **تعریف فعالیت:** ثبت عنوان، توضیح و تاریخ شروع (شمسی).
- **صفحهٔ پروژه:** تیزر سینمایی با دکمهٔ تمام‌صفحه، عنوان وسط‌چین، آمار قابل ویرایش، و فهرست آثار با جستجو، **فیلتر نوع اثر**، مرتب‌سازی (جدید/قدیمی/پربازدید/عنوان)، و دو نمای **آیکون بزرگ** و **لیستی**.
- **ثبت اثر:** نوع اثر قابل افزودن، **کلیدواژه با Enter** و آتوکامپلیت زندهٔ مبتنی بر دیتابیس (AJAX)، تاریخ رویداد (شمسی) و آپلود فایل.
- **بازدید پلتفرمی:** در حالت مدیریت، انتخاب پلتفرم‌ها (قابل افزودن/حذف) و ثبت بازدید هر پلتفرم؛ **مجموع** به‌صورت خودکار جمع می‌شود.
- **آثار مشابه:** زیر هر اثر، آثار مشابه بر اساس **اشتراک کلیدواژه (OR)** نمایش داده می‌شوند.

## ساختار
```
madar-app/
  server/   # API و دیتابیس
    db.js server.js package.json uploads/
  web/      # رابط کاربری
    index.html vite.config.js package.json
    src/ (App, api, jalali, components/...)
```

## نکته‌ها
- تاریخ‌ها در رابط کاربری **شمسی** نمایش داده می‌شوند ولی در دیتابیس به‌صورت میلادی (ISO) ذخیره می‌شوند تا فیلتر بازه دقیق باشد.
- برای استقرار واقعی: `cd web && npm run build` و سپس فایل‌های `web/dist` را پشت همان دامنهٔ بک‌اند سرو کنید.
